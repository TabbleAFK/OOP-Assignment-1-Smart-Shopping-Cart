# OOP-Assignment-1-Smart-Shopping-Cart

Hello!

The Smart Shopping Cart program allows users to enter and manage shopping information, including customer details, item names, quantities, and prices. It calculates the subtotal and final total, applies member discounts, and lets users update item quantities through a menu. The program demonstrates basic OOP concepts in Java, including classes, objects, constructors, encapsulation, getters, setters, and control structures.
